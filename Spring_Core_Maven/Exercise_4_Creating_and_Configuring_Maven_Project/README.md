# Exercise 4 - Creating and Configuring a Maven Project

## Objective

This exercise demonstrates how to create a basic Maven project and configure it for a Spring application.

## Files

- pom.xml

## Features

- Created a Maven project named LibraryManagement.
- Added Spring Context, Spring AOP, and Spring WebMVC dependencies.
- Configured the Maven Compiler Plugin for Java 1.8.

## Result

The project is ready for developing Spring-based applications using Maven.

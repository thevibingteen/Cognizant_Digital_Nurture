# Exercise 9 - Creating a Spring Boot Application

## Objective

Create a basic Spring Boot application for a library management system.

## Files

- pom.xml
- application.properties
- Book.java
- BookRepository.java
- BookController.java
- LibraryManagementApplication.java

## Features

- Spring Boot configuration
- Spring Web
- Spring Data JPA
- H2 in-memory database
- REST Controller
- CRUD repository

## Sample Endpoint

GET /books

POST /books

# Exercise 1 - Logging Error Messages and Warning Levels

## Objective

Learn how to configure and use the SLF4J logging framework in a Java application.

## Files

- pom.xml
- LoggingExample.java

## Description

This exercise demonstrates how to configure SLF4J with Logback and generate log messages using different logging levels such as INFO, WARN, and ERROR.

## Output

Sample log messages are displayed for application startup, warning notifications, error reporting, and successful program completion.

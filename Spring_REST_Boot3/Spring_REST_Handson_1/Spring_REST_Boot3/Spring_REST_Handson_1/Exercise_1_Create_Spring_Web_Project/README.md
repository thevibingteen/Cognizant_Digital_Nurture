# Hands-on 1 - Create a Spring Web Project using Maven

## Objective

Create a basic Spring Boot web application using Maven and verify that the application starts successfully.

---

## Files

- pom.xml
- application.properties
- SpringLearnApplication.java

---

## Technologies Used

- Java
- Maven
- Spring Boot 3
- Spring Web
- Spring Boot DevTools

---

## Steps Performed

1. Created a Spring Boot Maven project.
2. Added Spring Web and DevTools dependencies.
3. Configured application properties.
4. Created the main Spring Boot application class.
5. Verified successful application startup using log messages.

---

## Expected Output

```
Spring Boot application started successfully.
```

---

## Conclusion

The project demonstrates the basic setup of a Spring Boot web application using Maven and confirms that the application starts correctly.

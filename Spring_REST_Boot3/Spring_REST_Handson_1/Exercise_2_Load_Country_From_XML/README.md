# Exercise 2 - Load Country from Spring Configuration XML

## Objective

Read a Country bean from a Spring XML configuration file using the Spring IoC Container.

---

## Files

- Country.java
- country.xml
- SpringLearnApplication.java
- pom.xml

---

## Spring Concepts Used

- Bean Configuration
- XML Configuration
- Spring IoC Container
- ApplicationContext
- ClassPathXmlApplicationContext

---

## Configured Country

| Code | Name |
|------|------|
| IN | India |

---

## Expected Output

```
Inside Country Constructor.
Setting country code.
Setting country name.
Country : Country{code='IN', name='India'}
```

---

## Conclusion

This exercise demonstrates how Spring manages object creation and dependency configuration using an XML-based configuration file.

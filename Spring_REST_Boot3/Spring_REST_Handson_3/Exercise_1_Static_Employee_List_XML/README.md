# Exercise 1 - Static Employee List using Spring XML

## Objective

Create a static employee list using Spring XML configuration and retrieve it using a DAO class.

## Files

- Employee.java
- Department.java
- Skill.java
- EmployeeDao.java
- employee.xml
- SpringLearnApplication.java
- pom.xml

## Spring Concepts

- Bean Configuration
- XML-based Dependency Injection
- Collection Injection
- Spring ApplicationContext

## Output

The application loads the employee list from the XML configuration file and prints all employee details to the console.

## Result

Successfully demonstrated creating and retrieving a static employee list using Spring XML configuration.

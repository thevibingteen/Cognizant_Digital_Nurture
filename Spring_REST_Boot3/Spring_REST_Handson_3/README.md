# Spring REST Hands-on 3

## Overview

This module contains the remaining Spring REST hands-on exercises from the Cognizant Digital Nurture Program. The exercises demonstrate XML configuration, RESTful web services, and CRUD operations using Spring Boot.

---

## Exercises

### Exercise 1 – Static Employee List using Spring XML
- Configure employee data in Spring XML.
- Load employee information using Spring IoC.
- Display employee details.

### Exercise 2 – Employee REST Service
- Create REST APIs for employee information.
- Return employee data in JSON format.
- Test endpoints using Postman or a browser.

### Exercise 3 – Department REST Service
- Create REST APIs for department information.
- Return department details in JSON format.
- Demonstrate Spring REST controller functionality.

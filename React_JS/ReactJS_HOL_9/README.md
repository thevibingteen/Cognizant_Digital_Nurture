# ReactJS HOL 9

## Objective

Learn and implement ES6 features in React applications.

## Application

cricketapp

## Concepts Covered

- ES6 map()
- Arrow Functions
- Array filter()
- Destructuring
- Spread Operator (Merge Arrays)
- Conditional Rendering

## Components

- ListofPlayers
- IndianPlayers

## Features

- Display a list of 11 cricket players with their scores.
- Filter and display players with scores below 70 using arrow functions.
- Display odd and even team players.
- Merge T20 players and Ranji Trophy players using the spread operator.
- Render components conditionally using a flag variable.

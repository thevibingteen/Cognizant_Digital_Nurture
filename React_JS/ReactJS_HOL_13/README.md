# ReactJS HOL 13

## Objective

Learn and implement Conditional Rendering and List Rendering in React.

## Application

bloggerapp

## Concepts Covered

- Conditional Rendering
- Logical AND (&&)
- Ternary Operator
- List Rendering
- map() Function
- React Keys

## Components

- BookDetails
- BlogDetails
- CourseDetails

## Features

- Displays book details.
- Displays blog details.
- Displays course details.
- Demonstrates multiple methods of conditional rendering.
- Uses map() with keys to render lists.

# ReactJS HOL 15

## Objective

Learn and implement React Forms using controlled components.

## Application

ticketraisingapp

## Concepts Covered

- React Forms
- Controlled Components
- useState Hook
- Form Submission
- handleSubmit Event
- Textbox and Textarea

## Components

- ComplaintRegister

## Features

- Accepts employee name.
- Accepts complaint description.
- Uses controlled form inputs.
- Submits the form using handleSubmit.
- Generates a random complaint reference number.
- Displays the reference number in an alert box.
- Clears the form after successful submission.

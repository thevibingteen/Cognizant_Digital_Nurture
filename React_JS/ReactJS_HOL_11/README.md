# ReactJS HOL 11

## Objective

Learn and implement event handling in React applications.

## Application

eventexamplesapp

## Concepts Covered

- React Events
- Event Handlers
- Synthetic Events
- Passing Arguments to Event Handlers
- Multiple Function Invocation
- Class Components
- State Management

## Components

- EventExamples
- CurrencyConvertor

## Features

- Increment counter
- Decrement counter
- Invoke multiple methods with a single click
- Pass arguments to event handlers
- Demonstrate synthetic events
- Convert Indian Rupees (INR) to Euro (EUR)

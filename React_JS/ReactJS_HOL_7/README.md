# ReactJS HOL 7

## Objective

Understand and implement Props in React by passing data from a parent component to a child component.

## Application

shoppingapp

## Concepts Covered

- React Props
- Class Components
- Parent-Child Communication
- Component Reusability
- Rendering Lists using map()

## Components

- OnlineShopping
- Cart

## Features

- Displays a list of shopping items
- Passes item details from OnlineShopping to Cart using props
- Renders 5 shopping items in a table

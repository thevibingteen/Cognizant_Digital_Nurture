# ReactJS HOL 16

## Objective

Learn and implement React Form Validation using controlled components.

## Application

mailregisterapp

## Concepts Covered

- React Forms
- Controlled Components
- Form Validation
- useState Hook
- onChange Event
- onSubmit Event

## Components

- Register

## Validation Rules

- Name must contain at least 5 characters.
- Email must contain both '@' and '.'.
- Password must contain at least 8 characters.

## Features

- Real-time validation using onChange.
- Validation on form submission.
- Displays error messages for invalid inputs.
- Shows success alert after valid registration.

# ReactJS HOL 14

## Objective

Learn and implement the React Context API to avoid prop drilling.

## Application

Employee Management Application

## Concepts Covered

- React Context API
- createContext()
- Context Provider
- useContext()
- State Management
- Component Communication

## Files Modified

- App.js
- EmployeesList.js
- EmployeeCard.js
- ThemeContext.js

## Features

- Create ThemeContext with default value "light".
- Provide theme using ThemeContext.Provider.
- Consume theme using useContext().
- Remove unnecessary theme props.
- Change button theme dynamically.

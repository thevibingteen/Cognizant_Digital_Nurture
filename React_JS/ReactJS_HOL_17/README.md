# ReactJS HOL 17

## Objective

Learn how to consume REST APIs in React applications.

## Application

fetchuserapp

## Concepts Covered

- REST API Consumption
- Fetch API
- Class Components
- componentDidMount()
- React State
- Asynchronous Programming

## Components

- Getuser

## Features

- Fetches random user data from https://api.randomuser.me/.
- Uses componentDidMount() to call the REST API.
- Displays the user's title.
- Displays the user's first name.
- Displays the user's profile image.
- Shows a loading message while fetching data.

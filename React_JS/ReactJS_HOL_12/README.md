# ReactJS HOL 12

## Objective

Learn and implement Conditional Rendering in React.

## Application

ticketbookingapp

## Concepts Covered

- Conditional Rendering
- useState Hook
- React Components
- Event Handling
- Login/Logout Flow

## Components

- Guest
- User
- App

## Features

- Displays Guest page by default.
- Login button switches to User page.
- Logout button switches back to Guest page.
- Demonstrates conditional rendering using React state.

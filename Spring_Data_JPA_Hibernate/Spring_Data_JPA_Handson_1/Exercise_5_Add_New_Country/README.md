# Exercise 5 - Add New Country

## Objective

Implement a service method to add a new country using Spring Data JPA.

## Files

- Country.java
- CountryRepository.java
- CountryService.java
- CountryNotFoundException.java
- OrmLearnApplication.java
- application.properties

## Features

- Add a new country using the `save()` method.
- Retrieve the newly added country using its code.
- Demonstrate the use of `@Transactional`.
- Verify the insertion through the application.

## Expected Output

```
Start

Saved Country : NP : Nepal

End
```

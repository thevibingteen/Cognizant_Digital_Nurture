# Eureka Discovery Server

## Objective

Create a Eureka Discovery Server for service registration and discovery in a microservices architecture.

---

## Port

```
8761
```

---

## Dashboard

```
http://localhost:8761
```

---

## Technologies

- Spring Boot 3
- Spring Cloud Netflix Eureka
- Maven
- Java 17

---

## Features

- Service Registry
- Service Discovery
- Centralized Registration
- Dashboard for Registered Services

---

## Result

Successfully created a Eureka Discovery Server that enables microservices to register and discover each other automatically.
